# Contributing

This is primarily a personal reference, but if you're extending it (for yourself or via a PR):

1. **Categorize correctly.** Add each tool/resource under the closest matching heading in `README.md`. Propose a new heading only if nothing fits.
2. **One line per entry**, format: `- [Name](URL) — short description of what it does`.
3. **Only link real, maintained projects.** No dead links, no abandonware, no paywalled-only tools presented as free.
4. **No exploit code or live infrastructure** committed to this repo — link out to Exploit-DB/GitHub instead of pasting payloads for real, unpatched vulnerabilities.
5. **Notes and cheat sheets** go in `notes/` or `cheatsheets/`. Strip any client-identifying information, IPs, credentials, or scope details from anything committed here — engagement-specific material belongs in a private, access-controlled location, not this repo.
6. Keep the [Legal & Ethical Use](README.md#legal--ethical-use) section intact.
